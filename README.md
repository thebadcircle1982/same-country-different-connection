# Same Country. Different Connection.

A mobile-first data story about unequal access to high-speed Internet in Canada. The project supports UN Sustainable Development Goal 9: Industry, Innovation and Infrastructure.

## Project files

- `index.html` contains the page structure and campaign text.
- `styles.css` contains the responsive layout, colour system and visualizations.
- `app.js` controls the mobile menu and copy-message interaction.
- `assets/sdg9.png` is the SDG 9 graphic used in the campaign.

## Publish with GitHub Pages

1. Create a new public GitHub repository.
2. Upload all files from this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder.
6. Save and wait for GitHub to provide the public URL.

The site uses plain HTML, CSS and JavaScript and does not require a build process.
